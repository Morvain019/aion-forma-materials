# Aion Forma — библиотека конструктора Aion 2

[Открыть библиотеку](https://morvain019.github.io/aion-forma-materials/)

14 видео, 102 кадра и 62 раздела настроек. Можно искать ползунки, открывать отдельные кадры, перематывать видео и сохранять нужный момент.

Для помощи в ChatGPT передайте [ссылку на библиотеку](https://morvain019.github.io/aion-forma-materials/) и описание желаемой внешности. [Текстовый указатель](https://morvain019.github.io/aion-forma-materials/reference.txt) содержит названия настроек и ссылки на материалы.

Просмотр удалённых видео и извлечение кадров зависят от инструментов конкретного чата. Если материал не открывается, прикрепите готовый кадр к сообщению. Числа в демонстрациях — наблюдаемые значения, а не готовые рецепты внешности.

## Публикация

1. Разместите workflow в `.github/workflows/publish-pages.yml`. SHA256 текущего архива уже закреплён в нём; при обновлении материалов укажите проверенный хеш новой версии и новый тег релиза.
2. Добавьте в публичный релиз `v1.0.0` файлы `aion-forma-library.zip` и `aion-forma-library.sha256`. В корне ZIP должны лежать `index.html`, `reference.txt`, папки `knowledge/` и `media/`. Отдельный файл проверки предназначен для ручной сверки; его формат — `SHA256  aion-forma-library.zip` с двумя пробелами между хешем и именем.
3. В настройках репозитория откройте **Pages → Build and deployment → Source → GitHub Actions**.
4. Запустите **Actions → Publish Aion Forma library → Run workflow**.

Workflow сверяет архив с хешем, закреплённым в коде, затем публикует статическую библиотеку. Пароли, API-ключи и отдельные секреты не требуются.
